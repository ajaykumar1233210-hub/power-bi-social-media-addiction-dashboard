# Social Media Addiction Dashboard (Power BI)

## Objective
Study how social media usage, sleep and mental health relate to students' academic performance across countries and academic levels.

## Tools Used
Power BI: DAX measures, KPI cards, gauges, slicers, button navigation

## Dashboard Pages
1. Executive Overview
2. Mental Health & Lifestyle
3. Academic Impact
4. Relationships & Conflicts
5. Interactive Story View
6. Student Profile

## Key DAX Measures
- High Risk %
- % Affected Academically
- Addicted Student Count

## Project Files
- Social_Media_Addiction_Dashboard.pbix: the Power BI file
